# SANE backends that may enter the Engine's CMake set (ENGINE_BACKENDS).
#
# A backend is listed only when every file it compiles carries the SANE
# exception, it needs no vendor firmware file and it adds no dependency
# beyond libusb and libjpeg-turbo. Checked against sane-backends 1.4.0.
# Re-check a backend here on every upstream rebase before it ships: a
# maintainer can withdraw the exception (genesys did).
#
# A backend also ships only when it stops its reader thread as pixma does: a
# stop flag or a closed pipe, then a join. sanei_thread_kill cancels the
# thread asynchronously and can freeze the Engine process; see README,
# Changes to sane-backends 1.4.0, items 5 and 11.
#
# Never list (no exception): genesys, epson2, epsonds, xerox_mfp,
# canon_lide70, kodakaio, kvs1025, kvs20xx, kvs40xx, magicolor, hp4200,
# stv680, coolscan3. Never list (compiled files without the exception or any
# licence notice): epson (epson_scsi.c, epson_usb.c and their headers),
# canon630u (lm9830.h). Never list (vendor firmware): gt68xx, snapscan,
# epjitsu (every model it lists needs a .nal file from the vendor's driver).
# Not wanted (film scanners): pieusb, coolscan2.
